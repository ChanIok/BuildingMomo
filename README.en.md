## 🎯 About This Project

**BuildingMomo**

▸ Quickly move/copy/delete large building groups

▸ Freely merge building groups across different home schemes

▸ Visual coordinate editing with WYSIWYG interface

Designed for players with special building needs (complex building group adjustments, multi-scheme integration, batch grouping)

## 🚀 Quick Start

### 🌐 Online Editor

- [Cloudflare Pages](https://infinitymomo.com)
- [Vercel](https://building.infinitymomo.com)
- [Github Pages](https://chaniok.github.io/BuildingMomo)

### 💻 Local Development

If you're a developer or want to self-host:

Use Node.js 24 and pnpm.

```bash
# Install dependencies
pnpm install

# Build for production
pnpm run build
```

## 🛠️ Tech Stack

Vue 3 · Vite · Three.js · Tresjs · Pinia · Tailwind CSS · shadcn-vue
