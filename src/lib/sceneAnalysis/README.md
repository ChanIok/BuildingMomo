# 场景分析基础能力

编辑器无关的 DTO、几何、图像与组织命令。AI 协议、会话循环和存储统一在 `../ai/`。

- `snapshot.ts`：按精确成员构建不可变 DTO，复用共享位置、视觉旋转和缩放轴映射，不改家具。
- `geometry.ts` / `renderSnapshot.ts`：复用模型边界、显示补偿、飞花道和渲染矩阵，不拥有共享资源。
- `queries.ts` / `catalog.ts`：CLI 概况、字典与显式分页；分页无资产数量上限。自由筛选/聚类在 JS Worker 中执行。
- `images.ts`：透视相机、截图尺寸、图像布局与可取消任务的端口契约。
- `catalogAtlas.ts`：完整资产图册，调用方指定列数和单元格尺寸；默认四列 240×232，不限制类型数。
- `board.ts`：任意数量面板按指定布局合成一图；省略单元格尺寸时保留原分辨率。不自动拆页、不根据主观清晰度缩图。
- `organizeItems.ts` / `organizationState.ts`：组织命令与结果核验，写入只经 `useEditorOrganization` 正式事务。
- `captureBridge.ts`：视口发布共享渲染器截图能力，业务消费者不得释放库资源。
- `validation.ts` / `types.ts`：上述领域结构及校验。

`node scripts/analyze-scene.mjs temp/house.json` 输出只读概况；`--output temp/analysis.json` 显式保存完整快照。CLI 复用格式解析与家具尺寸边界，不下载模型、不调用 AI、不执行编辑。

位置/边界是世界空间厘米、Z 向上，旋转/缩放为视觉轴。AABB 接近不证明连接。场景截图仅透视，支持方位、俯仰、FOV、距离与显式瞄准点。自动取景逐实例拟合已加载模型的局部包围盒经实际显示矩阵变换后的角点；飞花道或缺少局部盒时使用现有世界 AABB。按当前视角的边界中心瞄准，不拟合合并大盒的空角，不扫描模型顶点；距离保留 8% 余量。`focus` 只控制取景，周围显示成员只扩展裁剪范围；显式瞄准点或距离优先。沿用当前光照，不含地形、天空和阴影。图册只是资产字典，不能把名称直接当作自由搭建中的用途。
